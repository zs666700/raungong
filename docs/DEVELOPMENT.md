# 出行计划智能助手 —— 文档索引

一个演示用的对话式出行规划助手：问一句 → 查天气/查地点 → 出带卡片的行程 → 数据全存下来。

## 三份文档

| 文档 | 读者 | 内容 |
|---|---|---|
| [后端文档](BACKEND.md) | 后端 | 架构、目录、配置、数据模型、**20 个接口**、**5 个 MCP 工具契约**、Agent 设计、RAG 实现、启动运维 |
| [前端文档](FRONTEND.md) | 前端 | 页面与路由、接口消费清单、api_client / ws_client 封装、**行程卡片渲染规则**、交互状态机 |
| [测试文档](TESTING.md) | 测试、开发自测 | 冒烟脚本、20 个接口用例、Mock 策略、**手工验收清单**、故障演练、**演示脚本** |

**契约以 [后端文档](BACKEND.md) 为唯一来源。** 前端与测试文档只描述"怎么用"，不重复定义字段。

## 技术选型

| 层 | 选型 |
|---|---|
| 后端 | FastAPI + SQLAlchemy 2.0（async）+ SQLite |
| Agent | LangChain + LangGraph `create_react_agent` + DeepSeek `deepseek-chat` |
| 工具 | **MCP**（stdio），两个独立子进程 `weather-mcp` / `place-mcp`，数据源高德 Web API |
| RAG | Chroma + BGE-M3（本地）+ pypdf/trafilatura |
| 鉴权 | JWT（HS256）+ argon2 |
| 前端 | NiceGUI（纯 Python，服务端渲染） |

## 模块划分

```
┌──────────────────────────────────────┐
│ 前端进程 NiceGUI :8080                │  只走 HTTP/WS，不 import 后端
└──────────────┬───────────────────────┘
               │ HTTP + WebSocket
┌──────────────▼───────────────────────┐
│ 后端进程 FastAPI :8000                │
│  api/ → services/ → agent/ / mcp      │
│  SQLite(app.db) + Chroma              │
└──────────────┬───────────────────────┘
               │ stdio / JSON-RPC
      ┌────────┴─────────┐
┌─────▼──────┐   ┌───────▼──────┐
│ weather-mcp│   │  place-mcp   │
│ 2 个工具    │   │  3 个工具     │
└─────┬──────┘   └──────┬───────┘
      └────────┬────────┘
        ┌──────▼───────┐
        │ 高德 Web API  │
        └──────────────┘
```

## 三条解耦约束（贯穿三份文档）

| 约束 | 收益 |
|---|---|
| 工具跑**独立进程**，经 MCP 通信 | 工具崩了主服务不死；换数据源只改 `mcp_servers/` |
| **Agent 只 yield 事件**，不碰 WebSocket | 流式接口与非流式接口复用同一套逻辑；断连后生成继续 |
| `api/` 不许直接 import `agent/` | 业务在 `services/` 收口，换 Agent 不牵动全局 |

## 从哪开始

1. 读 [后端文档第 18 章](BACKEND.md#18-启动与运维)，把环境跑起来

3. 按 [测试文档第 6 章](TESTING.md#6-手工验收清单) 的手工清单验收
4. 演示前照 [测试文档第 8 章](TESTING.md#8-演示脚本) 走一遍流程

## 演示当天要保住的四条链路

| # | 链路 | 一句话 |
|---|---|---|
| D1 | 登录与权限 | root 能管知识库，普通用户不能，root 看不到别人对话 |
| D2 | 对话 + 工具 | "查天气 → 搜景点 → 出卡片"完整可见 |
| D3 | 持久化 | 刷新、重启都不丢 |
| D4 | RAG | root 传文档 → 提问 → 回答带引用 |

## 明确不做的

限流、熔断、审计日志、异步任务队列、游标分页、ICS 导出、Docker 多容器、监控告警、多实例部署。

要做成上线产品时的补齐顺序见 [后端文档](BACKEND.md) 第 1.2 节（后端不负责清单）与第 18 章末尾的升级路径说明。
